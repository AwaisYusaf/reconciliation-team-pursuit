# Proposal: add the expense reference to the packet page footer

**For:** the funder / fiduciary reviewing Team Pursuit Global's monthly reconciliation packets
**From:** Team Pursuit Global
**Sample:** `reference-footer-sample.pdf` — one receipt page, shown as it appears today and as
proposed

---

## What we are asking for

Permission to add one item to the footer that **already appears on every page** of the packet.

| | |
|---|---|
| Today | `Team Pursuit Global — February 2026 — Page 84 of 132` |
| Proposed | `Team Pursuit Global — February 2026 — **2026-02-014** — Page 84 of 132` |

`2026-02-014` is the expense reference: a number unique within the month, already printed in the
packet's expense index. Nothing else about the page changes.

## Why

Every packet already contains an index listing each expense with its reference, date, payee, budget
category and amount. What it does not do is connect that index to the evidence.

A reviewer holding page 84 — a receipt, an invoice, a proof of payment — has no way to tell which
expense it supports without working backwards through the section headings and counting. For a
packet of 130 pages covering forty or more expenses, that is slow, and it is easy to get wrong.

Putting the reference in the footer closes that loop in both directions:

- From the index to the evidence: look up `2026-02-014`, turn to the pages carrying it.
- From the evidence to the claim: read the footer, find that reference in the index.

This is the only change needed to make the packet self-navigating. No explanation from us, and no
phone call, should be required for anyone to follow the financial trail.

## What does not change

- **The receipt, invoice or proof itself.** The footer is drawn in the packet's own bottom margin,
  below the page content, in the same small grey type as the existing footer. The source document
  is reproduced exactly as supplied.
- **The approved cover sheet.** Its three-column layout, wording and totals are untouched. This
  proposal deliberately avoids it.
- **Any figure.** No amount, total or percentage is affected.
- **The footer's position, size or colour.** The reference is inserted into the existing line.

## What we would do if you would rather we did not

We would instead improve our own index page — grouping it by budget category and adding the packet
page number for each expense. That is our page, so it needs no approval, and it makes the trail
followable in one direction (index → evidence) rather than both. We would prefer the footer, but
this is a workable alternative and we will take it if you prefer the source pages left entirely
unmarked.

## One related note

A month with an unusually large amount of evidence — for example a transport category with a full
month of individual ride receipts — can produce a packet above DocuSign's 25 MB envelope limit. We
reduce image quality automatically to try to stay under it, and if it still exceeds the limit we
send it anyway rather than leave documentation out. Please let us know if you would prefer a
different arrangement for those months, such as splitting the packet by category.
